# Endeavour Energy

> Endeavour Energy is the regulated electricity distribution network service provider (DNSP) for Greater Western Sydney, the Blue Mountains, the Illawarra, the Southern Highlands, the South Coast and Central West of New South Wales, Australia, delivering power to around 2.8 million people. It owns and operates the poles and wires; it does not sell energy, so it holds no retail billing relationship and no consumer usage API. What it does publish is a genuinely open, anonymous, key-free REST API over its physical grid — every pole, every conductor, every substation's spare capacity, and live outage feeds — served on the Opendatasoft Explore API v2.1 with a downloadable OpenAPI 3.0.3 contract.

## The API

Base URL: `https://data.endeavourenergy.com.au/api/explore/v2.1`

- Read-only. All 16 operations are GET; nothing can be created or changed.
- Anonymous. No signup, no key, no licence click-through. `GET /catalog/datasets` returns 200 with no credential.
- Quota: 5,000 calls/day, enforced per DOMAIN and shared across every anonymous consumer. Read `X-RateLimit-Remaining`.
- Query language: ODSQL (`select`, `where`, `group_by`, `order_by`, `refine`, `exclude`).
- Pagination: `limit` (max 100) + `offset`, with `offset+limit < 10000`. Anything larger must use the export endpoints.
- Errors: `{"error_code": "...", "message": "..."}`. Not RFC 9457.
- A deprecated v2.0 surface is still served at `/api/explore/v2.0` and returns `ODS-Explore-API-Deprecation` on every response.

Operations: `getDatasets`, `getDataset`, `getDatasetsFacets`, `getRecords`, `getRecord`, `getRecordsFacets`, `getDatasetAttachments`, `listExportFormats`, `listDatasetExportFormats`, `exportDatasets`, `exportCatalogCSV`, `exportCatalogDCAT`, `exportRecords`, `exportRecordsCSV`, `exportRecordsParquet`, `exportRecordsGPX`.

## What does NOT exist

State these plainly rather than guessing:

- **No consumer data API.** No usage, interval, billing or account data of any kind. Endeavour Energy does not bill consumers; the retailer holds the account.
- **No Consumer Data Right surface.** Verified against the authoritative register: `GET https://api.cdr.gov.au/cdr-register/v1/energy/data-holders/brands/summary` returned 84 energy brands, all retailers, with zero matches for Endeavour Energy or any Australian distribution network business. The CDR energy designation placed the data-holder obligation on retailers and on AEMO as gateway, not on the poles and wires. There is nothing to be non-compliant with.
- **No developer portal, no SDKs, no CLI, no Postman collection, no GitHub organisation, no status page, no API support channel, no changelog of Endeavour Energy's own.**
- **No events, webhooks, streaming or AsyncAPI.** Live data is polled, not pushed.
- **No GraphQL** (`/graphql` -> 404) and **no official MCP server**.
- **No published compliance program** — no SOC 2, ISO 27001 or trust centre.
- **CSIP-AUS exists but is undocumented.** Endeavour Energy operates a CSIP-AUS (IEEE 2030.5 derivative) utility server for NSW flexible exports and the emergency backstop mechanism. It is a real standards-based machine interface, but no endpoint, base URI, specification or developer onboarding is published for it. Do not invent one.
